GregTech: New Horizons is a Minecraft modpack built from many mods, each its own large codebase with many contributors.

## Contributions

I've worked on several of the mods in the pack, adding features that improve quality of life for players. That meant contributing Java to large, older codebases with many contributors: improving existing code and writing new code that will be used for a long time.

## Working in the open

I take part in code reviews with the development team to make sure contributions meet the project's standards. I also work with Git, GitHub, and GitHub Actions to build, test, and deploy new builds of the mods.
